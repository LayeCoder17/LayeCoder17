### Ce que je construis

**Plateforme DevSecOps** — mon projet de fin de cycle, conçu et développé seul, du serveur à l'interface. Une plateforme de gestion de projet reliée au code : une tâche n'est terminée que lorsque son code est fusionné, et un code qui contient une faille grave ne peut pas l'être.

- Serveur : Django REST Framework, Celery, Redis et PostgreSQL — 8 applications, 41 modèles, 219 tests
- Interface : React et Vite, avec mises à jour en temps réel par WebSockets
- Quatre outils d'analyse à chaque demande de fusion : Semgrep, Trivy, Gitleaks et SonarQube
- Fonctionne de la même façon avec GitHub et GitLab
- Détecte 95,6 % des failles de l'OWASP Benchmark (2 740 cas)

Le code est privé. Une démonstration est possible sur demande.

**En ce moment** — un programme d'entraînement en analyse de programmes : une machine virtuelle et un compilateur écrits en Python pur, vers un analyseur qui suit les données dangereuses dans le code.
